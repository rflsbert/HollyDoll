# HollyDoll

> Uma plataforma e-commerce para a compra de bonecas colecionáveus e edições especiais da Barbie.

## Sobre o projeto

A HollyDoll foi desenvolvida com foco em oferecer uma experiência nostálgica e marcante, sendo totalmente responsiva. A plataforma foi projetada para atender colecionadores e entusiastas do universo das bonecas, trazendo desde edições limitadas até coleções clássicas.

### Funcionalidades Principais

- **Home** : Carrosel de produtos, apresentação da marca, avaliações de clientes e dúvidas frequentes.
- **Carrinho de compras** : Parcialmente interativo, botões de comprar avisam que o item foi adicionado porém a página do carrinho não adiciona realmente os itens.
- **Autenticação** : Login e cadastro, com validação de senha e aviso de bem-vindo ao usuário.

## Tecnologias Utilizadas

- **Frontend:** React
- **Build Tool:** Vite
- **Estilização:** CSS3 (Flexbox / CSS Grid)
- **Versionamento:** Git & GitHub

## 🚀 Como Executar o Projeto

### Pré-requisitos
- [Node.js](https://nodejs.org/) (Versão 18 ou superior)
- `npm`

### Instalação e Execução:

```bash
# 1. Clone o repositório
git clone [https://github.com/rflsbert/HollyDoll.git](https://github.com/rflsbert/HollyDoll.git)

# 2. Acesse a pasta do projeto
cd Hollydoll

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev

# 5. Acesse o endereço indicado no terminal
http://localhost:5173


# OBS: se npm run dev não funcionar, utilizar 'npm.cmd run dev'.
